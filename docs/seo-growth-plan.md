# Keyly SEO 自然流量改善計劃書

## 目標

提升 Keyly 在台灣繁體中文 Google 搜尋中的非品牌曝光與合格自然流量，並將流量導向 App Store 下載。

## 現階段判斷

目前網站沒有明顯的全面索引阻擋；自然流量不足的主要原因，更可能是可排名內容太少、首頁搜尋主題不夠集中，以及網站權威尚未建立。

Google Search Console 已於 2026-08-09 完成連接。2026-08-11 查詢的 90 天基準顯示台灣只有 31 次曝光、2 次點擊，且目前可見 query 幾乎全是品牌字；英文首頁的大量曝光主要來自全球 `keyly` 同名搜尋，不能視為產品需求。詳細方法與後續檢查節奏見 [SEO 研究與 GSC 定期監測方式](seo/gsc-research-and-monitoring.md)。

首頁 H1、FAQ 初始 HTML、第一篇完全取用 Guide 與 GA4 載入方式已於 2026-08-09 完成修正。下列問題清單保留作為歷史決策背景，當前執行重點已轉為建立繁中非品牌搜尋入口。

## 問題優先順序

### 1. 可排名的內容頁太少

中文市場目前主要只有首頁具備搜尋價值，無法分別覆蓋「iPhone 注音鍵盤推薦」、「注音選字不準」、「第三方鍵盤安全」等不同搜尋意圖。這是目前最可能的主要流量瓶頸。

### 2. 首頁搜尋主題不夠明確

首頁 H1 偏向品牌文案，沒有直接表明 Keyly 是 iPhone／iPad 使用的 AI 注音鍵盤，可能削弱頁面與核心關鍵字的相關性。

### 3. FAQ 答案不在初始 HTML

FAQ 問題會出現在預渲染 HTML，但答案需要使用者互動後才產生。應優先修正內容渲染方式，確保搜尋引擎不執行互動也能讀取完整回答。FAQ Schema 不是此問題的主要解法。

### 4. 內容偏向廣告，缺乏決策資訊

現有內容能介紹功能，但缺少安裝教學、產品比較、適用裝置、操作示例及完整安全說明，較難滿足資訊型、問題解決型與商業比較型搜尋需求。

### 5. 網站權威與外部提及不足

Keyly 作為較新的產品及網站，難以只靠單一產品頁超過已有內容歷史、品牌知名度與外部連結的媒體及論壇。後續需要真實評測、媒體提及、社群討論與相關網站連結。

### 6. 分析數據可能漏記

GA4 目前延遲至使用者互動後或最多八秒才載入，可能漏記停留時間短且沒有互動的訪客。這會影響數據完整性，但不是搜尋流量不足的直接原因。

### 7. 次要技術改善

包含 Sitemap 更新日期、圖片替代文字及結構化資料完整度。這些項目值得修正，但預期影響低於內容覆蓋、首頁定位與網站權威。
