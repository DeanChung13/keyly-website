# Keyly SEO 研究與 GSC 定期監測方式

更新日期：2026-08-09

## 目的

用 Google Search Console（GSC）的第一手資料判斷 Keyly 的自然搜尋問題與內容機會，避免以 `site:` 查詢、非受控 SERP、推測搜尋量或單次排名取代正式數據。

目前透過本機 `search-console` MCP 以受限制使用者權限讀取 `sc-domain:keylyapp.com`。憑證與私鑰路徑不得寫入 repo、文件或對話紀錄。

## 證據分級

- **已證實**：由 GSC、正式站 HTTP 回應、建置後 HTML、原始碼或 Google 官方文件直接支持。
- **合理推論**：有證據支持，但仍需更多時間、樣本或其他資料驗證。
- **未知**：現有資料不足，不應用確定語氣描述。

所有排名、流量、CTR、索引與 Core Web Vitals 結論都必須註明資料來源、日期範圍、地區與維度。沒有來源的數字不得進入決策。

## GSC 查詢方法

### 日期

- 避開 GSC 尚未完整的最近資料，預設以查詢當日往前推 2 天作為結束日。
- 趨勢比較使用「最近完整 28 天」對「前一個 28 天」。
- 長期背景使用最近 90 天，不把 90 天平均值當成近期表現。

### 每次必查維度

1. 全站彙總：clicks、impressions、CTR、average position。
2. `page`：判斷曝光與點擊落在哪些頁面。
3. `query`：區分品牌與非品牌查詢。
4. `country`：台灣是主要決策市場。
5. `device`：確認手機搜尋表現。
6. `query × page`：確認查詢意圖與落地頁是否正確。
7. `query × country`：避免把全球同名搜尋誤認為台灣產品需求。

### 品牌與非品牌

- 品牌查詢包含 `keyly` 與明顯拼字變體。
- 非品牌查詢是未包含品牌名稱、直接描述需求或問題的查詢。
- 英文首頁的全球 `keyly` 曝光可能來自同名搜尋；未確認意圖前，不視為 AI 注音鍵盤的有效曝光。
- GSC 會因隱私門檻隱藏部分 query，因此 query 列表加總可能小於全站彙總；不得把未顯示的查詢擅自分類。

### 平均排名的限制

平均排名必須與 query、page、country 一起解讀。品牌字或全球同名搜尋可能讓全站平均排名看起來很好，但不代表「注音鍵盤」等產品詞已有排名。

## 定期檢查節奏

### 部署後立即

1. 確認正式 URL 回傳 200。
2. 確認 canonical、H1、主要正文與內部連結存在於初始 HTML。
3. 確認 sitemap 已包含新 URL，且 GSC 已讀到 sitemap。
4. 對新 URL 執行 URL Inspection，記錄索引狀態與最近抓取時間。

### 每週健康檢查

每週固定一天檢查一次；低流量階段不因單日波動改內容。

- 新 guide 是否已建立索引。
- Sitemap 是否成功、是否有錯誤。
- 台灣曝光與點擊。
- 中文首頁與 guide 的 page-level 曝光。
- 是否開始出現繁中非品牌 query。
- 是否出現抓取、canonical 或索引異常。

### 每 28 天決策檢查

比較最近完整 28 天與前一個 28 天：

- 台灣非品牌曝光是否增加。
- 哪些 query 對應到首頁或 guide。
- 新 guide 的曝光、點擊、CTR 與平均排名。
- 是否有排名約 8 至 20、值得加強的相關查詢。
- 手機與桌面表現是否有明顯差異。

CTR 或排名樣本很小時只記錄、不調整。若要採用最低樣本門檻，必須明確標示為團隊決策規則，不得宣稱是 Google 官方標準。

## 決策規則

| 觀察結果 | 下一步 |
|---|---|
| 新頁尚未索引 | 檢查 HTTP、canonical、robots、sitemap 與內部連結，再用 URL Inspection 驗證 |
| 已索引但 28 天完全無曝光 | 重新檢查搜尋意圖、title、H1、內容完整性與頁面是否過薄 |
| 有相關曝光，平均排名約 8–20 | 加強現有頁面的回答深度、證據與內部連結 |
| 有足夠曝光但 CTR 偏低 | 優先檢查 title 與 meta description 是否符合查詢意圖 |
| 出現新的相關非品牌 query | 用 query 決定下一篇 guide；一個主要意圖對應一個頁面 |
| 只有品牌或全球同名曝光 | 不擴張英文內容；繼續建立台灣繁中問題型搜尋入口 |

## GA4 與 GSC 的分工

- **GSC**：搜尋曝光、點擊、query、page、country、device、索引狀態。
- **GA4**：進站後互動、下載按鈕與其他轉換事件。

2026-08-09 起，GA4 從互動／8 秒後延遲載入改為官方 async 安裝。此前後的 GA4 流量不可直接當作純流量成長比較；必須標記追蹤方式變更日。GSC 搜尋點擊不受這項改動影響。

## 不採用的研究方式

- 不用 `site:` 結果數量作為精確索引頁數。
- 不把未控制地區、語言、裝置與個人化的手動 SERP 當成正式排名。
- 不以全站平均排名代替非品牌產品詞排名。
- 不用頁數或字數單獨判斷內容品質。
- 不承諾 FAQ Schema、內容增加或 metadata 修改會帶來特定排名或 CTR 成長。
