# `iPhone 注音鍵盤推薦` 既有比較頁 SEO 優化 Brief

建立日期：2026-08-11  
實作頁面：`https://keylyapp.com/guides/iphone-zhuyin-keyboard/`  
任務類型：既有頁優化，不新增頁面

## 目標

提升台灣 Google 非品牌曝光，讓既有比較頁承接「推薦／比較／選擇」意圖。首頁繼續承接 `iPhone 注音鍵盤` 的產品意圖；本頁不得改成第二個產品首頁。

## 決策證據

Google Trends 條件皆為台灣、過去一年、網頁搜尋：

- `注音鍵盤` 平均相對熱度 66，`注音輸入法` 為 64。
- `注音輸入法` 的相關查詢混有華碩、新酷音、搜狗等跨平台需求，不能全部視為 iPhone 商機。
- `注音鍵盤` 的飆升查詢包含「鍵盤推薦」(+80%)、「超注音」(+50%) 與「iPhone 鍵盤」(+6%)，和本頁現有的 iPhone 鍵盤比較內容吻合。
- 百分比是相對成長，不是搜尋次數；本輪不宣稱任何月搜尋量。

## 關鍵字與意圖分工

- 主要：`iPhone 注音鍵盤推薦`
- 次要：`注音鍵盤推薦`、`iPhone 注音輸入法推薦`
- 支援語意：`iPhone 注音鍵盤比較`、`超注音`、`第三方鍵盤`

不得刻意追逐泛用 `注音輸入法`，也不得為每個同義詞建立新頁。

## MVP 修改範圍

### 1. Metadata

Title 改為：

`2026 iPhone 注音鍵盤推薦：內建與 5 款第三方比較`

Meta description 改為：

`比較 iPhone 內建注音與 Keyly、Gboard、胖打注音、超注音、UrKeyboard 的選字方式、離線能力、AI 功能、價格與適合族群，快速選出符合需求的注音鍵盤。`

同步更新 `og:title`、`og:description` 與現有 WebPage JSON-LD 的 `name`、`description`。canonical、hreflang、URL 與發布日期不得變更。

### 2. H1 與首段

H1 改為：

`2026 iPhone 注音鍵盤推薦：內建與 5 款第三方完整比較`

利益揭露保留。其後的「30 秒結論」第一段需直接回答選擇問題：沒有單一鍵盤適合所有人，應依選字習慣、離線需求、AI 功能、價格與權限接受程度選擇。

本輪只調整首段的搜尋意圖對齊，不重寫全文。

### 3. 既有標題微調

- `先決定你需要哪一種 iPhone 注音鍵盤` 保留。
- `iPhone 注音鍵盤比較表` 保留。
- 結尾 H2 `選哪一款，取決於你的需求` 改為 `iPhone 注音鍵盤怎麼選？依需求做最後決定`。

全文自然出現一次 `注音鍵盤推薦` 即可；不得為密度重複插入關鍵字。

### 4. 內容與事實邊界

保留目前六個比較對象、比較欄位、官方來源、利益揭露與「官方頁面未說明」原則。除非重新查證官方資料，否則不得修改價格、版本、系統需求、離線能力或功能判定。

不得：

- 宣稱 Keyly 是最好、最準或第一名。
- 把 Trends 成長百分比寫進公開頁面。
- 新增競品比較結論或排行榜名次。
- 新增 FAQ、Schema、競品頁或同義 Guide。
- 重做版面、比較表或視覺設計。

### 5. 內部連結與 GA4

沿用既有首頁與本頁之間的連結，不新增全站頁尾連結。保留現有 `download_click`、競品來源 `link_click` 與事件 label；本輪不新增事件種類。

## MVP 驗收

1. URL、canonical、hreflang 不變，頁面只有一個 H1。
2. Title 與 H1 以 `2026 iPhone 注音鍵盤推薦` 起頭。
3. Description 清楚描述六個比較對象與決策維度。
4. 初始 HTML 包含 Title、H1、30 秒結論、比較表與 FAQ。
5. 六個比較對象、官方來源與利益揭露完整保留。
6. 沒有新增 URL、Schema、事件種類或大量內部連結。
7. `npm run lint` 與 `npm run build` 通過。
8. 部署後驗證正式 URL 200、無斜線版本 308、canonical 正確，手機比較表仍可水平捲動且整頁不橫向溢出。
