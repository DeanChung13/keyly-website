## 結論

Keyly 過去的 Google 曝光主要不是台灣輸入法需求，而是英文首頁在全球同名 `keyly` 查詢中的曝光。全站平均排名看似靠前，但不能代表台灣注音鍵盤 SEO 表現。

台灣目前仍接近零基準：90 天共 31 次曝光；最近 28 天 11 次；最近 7 天 4 次。GSC 可見的台灣 query 只有品牌詞 `keyly`，沒有可見的非品牌查詢。由於 GSC 會隱藏部分低量 query，本文不得把「可見非品牌為 0」寫成「所有非品牌曝光絕對為 0」。

### 曝光來源的錯位

- GSC page 維度在 90 天內回報英文首頁 `/en/` 637 次曝光；中文首頁 `/` 55 次。
- country 維度回報美國 243 次曝光，台灣只有 31 次。
- 可見 query 中，`keyly` 有 492 次曝光；其他可見詞是 `keylies`、`keyliy`、`keyply`、`kliy` 等同名或拼字變體。
- 台灣可見的 query × page 配對只有 `keyly` → 中文首頁，共 3 次曝光；其餘台灣曝光的 query 因隱私門檻未顯示。

因此，原本的全站曝光與平均排名主要反映全球同名搜尋，不是「台灣使用者搜尋 iPhone 注音鍵盤找到 Keyly」。

## 資料限制

GSC 各維度受到匿名查詢與隱私門檻影響：

- 全站 90 天總曝光為 687，但 query 維度顯示的列合計只有 496 次曝光。
- 台灣 90 天總曝光為 31，但 country × query × page 可見列只顯示 3 次。
- 不可見差額不能自行歸類為品牌或非品牌。
- page、query、country 等不同維度的列合計可能不完全等於彙總值，不應混合後推算不存在的精確比例。

後續報告必須分開呈現「總曝光」與「可見 query 曝光」。

## 對 SEO 決策的影響

1. **真正問題是缺少台灣非品牌搜尋能見度。**目前沒有足夠資料支持 CTR、下載轉換或排名微調是主要瓶頸。
2. **不能再用全站平均排名判斷成效。**它主要受到 `keyly` 同名搜尋影響。
3. **新 Guide 尚未被這份基準充分涵蓋。**資料截止 2026-08-09，多數新頁在截止日前後才部署，因此這份報告是上線前／早期基準，不是新內容成效判決。
4. **下一階段必須從外部需求與 SERP 找機會。**GSC 沒有足夠非品牌 query 可供「排名 8–30 優化」，不能只靠既有資料選題。

## 第一階段判定

曝光基準已建立，可以進入搜尋需求與 SERP 機會研究。日曝光 100 的目標應以「台灣非品牌」單獨衡量，不納入全球同名 `keyly` 曝光。
