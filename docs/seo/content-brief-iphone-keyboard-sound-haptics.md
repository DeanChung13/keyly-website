# `iPhone 鍵盤聲音` 既有震動頁 SEO 優化 Brief

建立日期：2026-08-11  
實作頁面：`https://keylyapp.com/guides/iphone-keyboard-haptics/`  
任務類型：既有頁優化，不新增頁面

## 目標

讓既有頁同時承接 `iPhone 鍵盤聲音` 與 `iPhone 鍵盤震動` 的同一組系統設定意圖，增加台灣非品牌曝光。

## 決策證據

- Google Trends「iPhone 鍵盤」熱門相關查詢中，`iPhone 鍵盤聲音` 排名第 3。
- 既有頁已引用 Apple 官方「更改 iPhone 鍵盤聲音或觸覺回饋」，並說明聲音與觸覺回饋是獨立開關。
- 因此只需補強既有頁的搜尋意圖，不需要新的聲音 Guide。

Trends 排名是相對訊號，不是搜尋量，不得寫入公開頁面。

## 關鍵字

- 主要：`iPhone 鍵盤聲音`
- 共同主要意圖：`iPhone 鍵盤震動`
- 次要：`iPhone 打字聲音`、`鍵盤聲音關閉`、`鍵盤觸覺回饋`

## MVP 修改範圍

### 1. Metadata

Title：

`iPhone 鍵盤聲音與震動怎麼開？設定與沒反應排查`

Meta description：

`說明 iPhone 鍵盤聲音與震動的開關位置、兩種回饋的差異，以及觸覺回饋沒反應時的官方檢查步驟；另整理第三方鍵盤可能不同的設定與權限條件。`

同步更新 `og:title`、`og:description` 與 WebPage JSON-LD 的 `name`、`description`。URL、canonical、hreflang、日期與 Schema 類型不變。

### 2. H1 與 30 秒答案

H1：

`iPhone 鍵盤聲音與震動怎麼開？設定與沒反應排查`

30 秒答案必須先提供同一條 Apple 路徑：

1. 「設定」→「聲音與觸覺回饋」。
2. 「鍵盤回饋」。
3. 分別開啟或關閉「聲音」與「觸覺回饋」。

明確說明兩者是獨立開關，不得暗示開啟其中一項會自動開啟另一項。

### 3. 聲音設定段落

在 30 秒答案後新增一個精簡 H2：

`iPhone 鍵盤聲音怎麼開啟或關閉`

內容限於：

- 重述 Apple 官方路徑與「聲音」開關。
- 說明這條路徑先用來檢查 Apple 內建鍵盤。
- 第三方鍵盤可能另有自己的聲音設定，需查看該鍵盤設定。

不得加入未由 Apple 文件支持的靜音模式、音量、Bug 原因或保證性排錯結論。

### 4. 既有內容邊界

保留目前所有震動、耗電、第三方鍵盤裝置實測、FAQ、Apple 來源、GA4 事件與單一下載 CTA。除上述指定位置外，不重寫全文。

不得：

- 新增 URL、Schema 或事件種類。
- 建立另一篇鍵盤聲音文章。
- 宣稱 Keyly 的震動行為是 Apple 官方規則。
- 順帶擴寫鍵盤大小、背景、動態調整等旁支主題。

## MVP 驗收

1. Title 與 H1 以 `iPhone 鍵盤聲音與震動` 起頭，全頁一個 H1。
2. 初始 HTML 包含完整 30 秒設定路徑與新增聲音 H2。
3. 聲音與觸覺回饋明確標示為兩個獨立開關。
4. Apple 官方來源、既有震動排查、第三方鍵盤實測邊界與 FAQ 完整保留。
5. URL、canonical、hreflang、Schema 類型、GA4 事件與 CTA 數量不變。
6. `npm run lint` 與 `npm run build` 通過。
7. 部署後正式 URL 200、無斜線版本 308、canonical 正確，手機版無明顯破版。
