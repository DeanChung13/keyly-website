# 首頁 `iPhone 注音` 主題群 SEO 優化 Brief

建立日期：2026-08-11  
實作頁面：`https://keylyapp.com/`  
任務類型：既有首頁優化，不新增頁面

## 決策依據

### GSC 基準

- 台灣 90 天只有 31 次曝光、最近 28 天 11 次、最近 7 天 4 次。
- 可見的台灣 query 沒有非品牌詞；全球曝光主要來自英文首頁與同名 `keyly`。
- 因此本輪目標是建立台灣非品牌能見度，不優先處理 CTR 或轉換率。

### Google Trends

條件皆為台灣、過去一年、網頁搜尋：

- 第一組：`iPhone 鍵盤` 60、`注音輸入法` 49、`AI 鍵盤` 10、`中文打字測試` 0。
- 第二組：`iPhone 注音` 27、`iPhone 輸入法` 6；`iPhone 鍵盤推薦`、`注音輸入法推薦`、`iPhone 第三方鍵盤` 均為 0。
- 第三組：`iPhone 注音鍵盤` 3；`iPhone 注音設定`、`iPhone 注音選字`、`iPhone 注音不準`、`iPhone 注音動態調整` 均為 0。`iPhone 注音鍵盤` 的訊號集中在近期，應視為需後續驗證的上升訊號，不宣稱已形成長期趨勢。

Trends 是相對指數，不是月搜尋量；數值 0 代表資料不足或相對極少，不代表絕對無搜尋。

### SERP

`iPhone 注音` 公開結果包含 Apple／媒體教學、鍵盤配置、動態調整、Gboard 舊教學、iOS 26 鍵盤變更及 Keyly 中文首頁。Keyly 已具備初步相關性，但搜尋意圖混合。

## 核心決定

首頁作為以下主題的唯一主要承接頁：

- 主要：`iPhone 注音`
- 主要變體：`iPhone 注音鍵盤`
- 次要：`iPhone 注音輸入法`、`繁體中文注音鍵盤`

既有比較頁繼續承接「比較／推薦」意圖，不建立另一個泛 `iPhone 注音` Guide，避免首頁與 Guide 互相競爭。

## MVP 修改範圍

### 1. Title

建議改為：

`iPhone 注音鍵盤｜繁體中文 AI 輸入法 - Keyly`

理由：把已驗證的產品主題放在最前方，品牌保留在結尾；不再以 `Keyly` 或較窄的 `AI 注音鍵盤` 起頭。

同步更新 `og:title` 與 `twitter:title`，但不得修改 canonical 或語言設定。

### 2. H1 與首屏定位

H1 第一行改為精確且自然的：

`iPhone 注音鍵盤`

原本的 AI 價值主張保留在第二行或副標，不刪除產品差異。首段應在不堆疊關鍵字的前提下說明：

- 為 iPhone／iPad 與繁體中文設計。
- 核心是注音輸入與選字；AI 潤飾、翻譯、改寫是附加工作流程。
- 離線注音輸入與需要連線的雲端 AI 不得混寫。

### 3. 首頁主要內容

在功能區標題或首個可讀段落自然使用一次 `iPhone 注音輸入法`，並清楚區分：

- 一般注音輸入。
- AI 文字功能。
- 隱私與完全取用說明。

不得為了關鍵字增加新的長篇 Guide 區塊；現有比較、選字排查、完全取用頁用情境式內部連結承接細節。

### 4. 文案可信度

本輪順帶移除無證據的絕對比較或最高級語氣，例如「最好」、「頂級」、「最完美」、「絕對」、「精準除錯」等。可以描述實際功能與設計目標，但不得宣稱優於所有 iOS 鍵盤或保證選字結果。

### 5. 結構與索引

保持：

- URL、canonical、`zh-TW`／`x-default` hreflang。
- 一個 H1。
- 初始 HTML 可讀正文。
- 現有 GA4 `download_click` 與內部連結事件。
- SoftwareApplication schema 的產品事實一致性。

不新增 FAQPage schema，不建立新 URL，不修改英文首頁。

## 禁止事項

- 不把 Trends 指數寫成搜尋量。
- 不在正文重複堆疊 `iPhone 注音`。
- 不新增「推薦」同義頁。
- 不把 Apple 內建鍵盤設定說成 Keyly 的功能。
- 不宣稱 Keyly 有自己的手寫或語音功能。
- 不趁本輪重做視覺、效能或整個首頁架構。

## MVP 驗收

1. Title 以 `iPhone 注音鍵盤` 起頭，canonical 不變。
2. H1 第一行為 `iPhone 注音鍵盤`，全頁仍只有一個 H1。
3. 首屏正文清楚區分離線注音輸入與 AI 功能。
4. 初始 HTML 包含主要標題與首段，不依賴互動後掛載。
5. 無新增 URL、無新 Schema、無大量內部連結。
6. 無上述絕對／最高級產品宣稱殘留。
7. `npm run lint` 與 `npm run build` 通過。
8. 部署後首頁 200、canonical 正確、行動版首屏沒有明顯破版。

## 28 天判定

GSC 只看台灣、Web、首頁，分開記錄：

- `iPhone 注音`
- `iPhone 注音鍵盤`
- `iPhone 注音輸入法`
- 其他新出現的非品牌 query

第 7、14 天只確認是否出現曝光；第 28 天比較首頁台灣非品牌曝光與本輪基準。若有曝光且排名 8–30，繼續優化同一首頁；若完全無曝光，重新檢查需求與網站權威，不建立另一個同義頁。
