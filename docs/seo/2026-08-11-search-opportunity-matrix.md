# Keyly 搜尋需求與 SERP 機會矩陣

研究日期：2026-08-11  
市場目標：台灣／繁體中文／Google 非品牌搜尋

## 研究狀態

本輪是公開 SERP 與 Google Trends 的第一輪篩選，不是最終關鍵字排名。搜尋結果能證明意圖與競爭形式存在；Google Trends 只能比較相對熱度，不能提供精確台灣月搜尋量。

使用者於 2026-08-11 提供 Google Trends 截圖，條件為台灣、過去一年、網頁搜尋。四個搜尋字詞的平均相對熱度為：

| 搜尋字詞 | 平均相對熱度 |
|---|---:|
| `iPhone 鍵盤` | 60 |
| `注音輸入法` | 49 |
| `AI 鍵盤` | 10 |
| `中文打字測試` | 0 |

這是同一組比較中的相對指數，不是搜尋次數。數值 0 代表相對資料極少或不足，不代表絕對無人搜尋。

第二組比較使用相同條件，結果為：

| 搜尋字詞 | 平均相對熱度 |
|---|---:|
| `iPhone 注音` | 27 |
| `iPhone 輸入法` | 6 |
| `iPhone 鍵盤推薦` | 0 |
| `注音輸入法推薦` | 0 |
| `iPhone 第三方鍵盤` | 0 |

因此，推薦與第三方鍵盤等直接商業詞在 Trends 樣本中資料不足；真正有明顯訊號的是較寬的 `iPhone 注音`。下一步應拆解其子意圖，而不是繼續建立「推薦」同義頁。

第三組比較使用相同條件，結果為：

| 搜尋字詞 | 平均相對熱度 |
|---|---:|
| `iPhone 注音鍵盤` | 3 |
| `iPhone 注音設定` | 0 |
| `iPhone 注音選字` | 0 |
| `iPhone 注音不準` | 0 |
| `iPhone 注音動態調整` | 0 |

`iPhone 注音鍵盤` 的訊號集中在近期並出現上升，不應解讀成已證實的長期成長；但它是五個子意圖中唯一有可見資料者，且與 Keyly 產品完全一致。

第四組比較使用相同條件，結果為：

| 搜尋字詞 | 平均相對熱度 |
|---|---:|
| `注音輸入法` | 64 |
| `手機注音輸入法` | 0 |
| `iOS 注音輸入法` | 0 |
| `注音鍵盤` | 66 |
| `繁體中文輸入法` | 0 |

相關查詢顯示，`注音輸入法` 混有華碩、小麥、新酷音與搜狗等跨平台／品牌需求；不能把 64 全部視為 iPhone 商機。相較之下，`注音鍵盤` 的飆升查詢包含「鍵盤推薦」(+80%)、「超注音」(+50%) 與「iPhone 鍵盤」(+6%)，與既有 iPhone 注音鍵盤比較頁的決策意圖直接相符。百分比是相對成長，不是搜尋量。

## 第一輪事實觀察

### 1. 大量曝光不能只靠現有 GSC 查詢擴寫

[GSC 基準](2026-08-11-gsc-exposure-baseline.md)沒有足夠的台灣非品牌 query，因此目前不存在一批「已排名 8–30」的台灣詞可直接推升。需求研究必須先從公開 SERP 與免費相對趨勢資料建立候選，再等待新頁 GSC 驗證。

### 2. 工具不是自動的第一名

`中文／注音打字速度測試` 的確存在工具意圖，但 TypeMate、華語 GO 等現有產品已提供速度、正確率與練習；台灣 Trends 比較中 `中文打字測試` 又只有 0。Keyly 若只複製計時與正確率，不但沒有明顯競爭優勢，也缺少足夠的相對需求證據，因此從候選第一名降級。

### 3. 新功能頁的正確需求可能不是功能名稱

公開結果中，`雙拼`、`小鶴雙拼` 很多內容面向中國簡體市場。對台灣更可能成立的問題是「在 iPhone 用拼音輸入台灣繁體字」或「不會注音如何在 iPhone 打繁體中文」。這是待驗證假設，不先建立全拼、雙拼、小鶴各一頁。

### 4. Apple Intelligence 通用詞不是主攻方向

Apple 官方完整承接書寫工具能力、支援語言與操作方式。Keyly 不應重複官方內容；現有頁應只競爭「舊機型或不同工作流程是否需要 AI 鍵盤」的決策意圖。

### 5. `iPhone 注音` 是目前最值得繼續拆解的需求

第二組 Trends 中，`iPhone 注音` 的相對熱度 27，明顯高於 `iPhone 輸入法` 的 6；三個推薦／第三方詞皆為 0。公開 SERP 同時出現鍵盤設定、動態調整、鍵盤太小、輸入技巧、Gboard 教學、iOS 26 鍵盤變更與 Keyly 中文首頁。

這表示廣泛需求存在，但意圖混合。現階段不能直接把它當成「找第三方輸入法下載」，必須再分辨設定、鍵盤配置、選字問題與替代方案的相對需求。Keyly 首頁已能出現在公開結果中，是應優先評估的既有承接頁，不先建立另一個泛 `iPhone 注音` 頁面。

### 6. `注音鍵盤` 應由既有比較頁承接

第四組 Trends 證明，廣泛的 `注音輸入法` 需求混有不同平台與品牌；直接追逐該詞，可能帶來與 iPhone App 無關的曝光。`注音鍵盤` 的相關查詢則出現推薦、超注音與 iPhone 鍵盤，和使用者選擇鍵盤的決策情境吻合。

因此不建立新的同義 Guide。下一個零成本 SEO 實驗應只調整既有 `iphone-zhuyin-keyboard` 比較頁，使 Title、H1、開頭與比較摘要自然涵蓋「iPhone 注音鍵盤推薦」，同時保留比較意圖，避免與承接產品意圖的首頁互相競爭。

## 下一個決策門檻

四輪 Trends 與公開 SERP 已足以完成本次頁面選擇：以中文首頁承接 `iPhone 注音`／`iPhone 注音鍵盤`，不再新增泛用 Guide。完整修改邊界與驗收方式見 [首頁 SEO 優化 Brief](content-brief-homepage-iphone-zhuyin.md)。

下一步依序使用免費來源：

1. 依 [首頁 SEO 優化 Brief](content-brief-homepage-iphone-zhuyin.md) 完成一次小幅、可回復的既有頁優化。
2. 部署後第 7／14 天確認 `iPhone 注音` 主題是否開始出現曝光。
3. 同步準備既有比較頁的單頁優化 Brief，承接 `iPhone 注音鍵盤推薦`／`注音鍵盤推薦` 的比較意圖；不新增 URL。
4. 第 28 天才用 GSC 的台灣 query × page 判斷首頁與比較頁是否各自取得產品意圖與比較意圖曝光。

取得上述訊號後，才依研究計畫的 100 分制產出前三名與第一個 MVP brief。
